# Admin Dashboard Redesign

- Removed the duplicate customer Call Rider action.
- Admin dashboard now shows one workspace at a time: Orders, Payments, Operations, Rider Map, Reviews, or Analytics.
- Sticky workspace tabs include counters.
- Orders are paginated at 8 records per page.
- Search and status filters remain available.
- Stat cards switch directly to the relevant workspace.
- No database migration is required.
