# Barangay Express V9 — Control Room Polish

This release refines the compact admin dashboard without changing booking, payment, wallet, map, or first-win dispatch logic.

## Improvements

- Smaller command-center banner and KPI cards
- Richer active-delivery cards with rider, pickup, and drop-off context
- Timeline-style activity feed
- Clear rider states: Available, Delivering, Offline
- More compact revenue pulse with hover values and current-day highlight
- Compact live GPS field summary
- Reduced vertical spacing across the overview

No SQL migration or new npm package is required.
