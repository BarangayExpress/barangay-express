# Barangay Express Admin Dashboard V7 — Compact Desktop Polish

This release keeps the V6 live-operations features and business logic, while reducing desktop visual scale by roughly 15–20%.

## Changes
- Sidebar reduced from 288px to 256px
- Header reduced from 80px to 64px
- More compact navigation rows and controls
- Smaller hero typography and padding
- Denser KPI cards
- Reduced dashboard gaps and section padding
- Revenue chart reduced in height
- Recent activity rows made more compact
- Mini operations map reduced in height
- Right-side operations column narrowed for better information density

No database migration or new npm package is required.
